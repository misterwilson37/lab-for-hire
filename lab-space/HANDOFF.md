## 3. Merging into `index.html` (main-game session 4)
1. **Paste the module.** Copy the whole `<script id="lab">…</script>` block from `src/lab_template.html` into `index.html`. It injects its own CSS (`<style id="labroom-css">`) and inherits the page font.
2. **Add three generated JSON blocks** the same way `lfh-content` is generated: `<script type="application/json" id="lab-items">`, `id="lab-manifest"`, and `id="lab-sprites"` (a map of file name → data URI). `src/build_lab.py` shows exactly how. Extend `tools/embed_content.py` to do it, so the lab stays one self-contained file.
3. **Add the lab to saved progress.** Put it in `lfh.progress` as `progress.lab`. For old saves, `LabRoom.normalize(progress.lab, items)` returns a valid lab (the starter lab when empty).
4. **Mount it:**
   ```js
   const lab = LabRoom.mount(el, {
     state: progress.lab,
     items,                       // optional; defaults to the lab-items block (later: the Items tab from the feed)
     rank: rankIndex,             // the game's rank index; "Rank required" in the Items tab compares against this
     rankName: (n) => RANKS[n].name,
     onChange: (next, ev) => { progress.lab = next; saveProgress(); }   // ev.type: buy | place | remove | paint
   });
   ```
5. **Pay funds from the game, never from the module.** At the end of a case: `const s = lab.getState(); s.funds += earned; lab.update(s); lab.say("+$40 for solid evidence")`. The module only ever spends.
6. **Gate cases by what the student owns.** `LabRoom.unlocks(progress.lab, items)` returns keys like `["cells"]`. Unlocks come from **owning** equipment, not from placing it, so rearranging the room never locks a case.
7. **Rank changes:** call `lab.setRank(n)`.
8. **Remove the old placeholder.** Delete the emoji lab shelf, and delete the demo glue (`<script id="lab-demo">`). Don't merge the `lfh.labDemo` key.

**Full module API:**
- `LabRoom.mount(el, opts)` returns a handle with `getState()`, `update(state)`, `setRank(n)`, `say(msg)`, `unlocks()`, and `destroy()`.
- `LabRoom.defaultState(items)`, `LabRoom.normalize(state, items)`, and `LabRoom.unlocks(state, items)` are pure functions.
- Other mount options:
  - `manifest` and `sprites`: default to the page's JSON blocks.
  - `spriteBase`: a folder URL, used if sprites are not embedded.
  - `unlockLabels`: overrides the chip text.
  - `readOnly`: room only, no panel.

**Lab state** (all item IDs, no PII):
```js
{ funds: 70, owned: ["desk", "microscope", …],
  placed: { bench: "desk", "bench-3": "microscope", … },   // spot id → item id
  paint: { wall: "wall-lavender", floor: "floor-lilac", trim: "trim-purple", tiles: "tiles-plain" } }   // paint stores item IDs, not colors
```

**Content schema:** the Items tab is new content, so bump the content schema to **0.3.0** when it joins the feed. `LFH.validate` should add these checks (`tools/lab-bake/bake.py → validate()` already does them and can be ported):
- IDs are unique.
- Kind is Equipment, Cosmetic, or Theme.
- Slot names a real spot type.
- Sprite names a baked look (or a `#hex` or pattern on paint rows).
- There is exactly one starter row for each paint kind.

## 4. Decisions made (and why)
- **14 spots, not the brief's 10–12.** The bench holds three items (left, middle, right). With 12, equipment would crowd out the beaker and flask.
- **39 Items rows, not about 20.** 11 are the free starter rows (including four paint rows), and 7 more are paint colors. There are about 21 real things to buy.
- **Save code deferred to main-game session 2** (funds, store stub, save code), as that session already plans. It belongs to the whole `lfh.progress`, not just the lab.
- **The demo has its own storage key** (`lfh.labDemo`), so Hanson trying the demo can never damage a student's real save on the same `github.io` address.
- **Furniture sits against the baseboard trim**, not inside it. The desk, bookcase, and floor machine moved about 6 cm forward.
- **Bookcases are sized by their top board**, so both bookcases share one shelf-top surface and one set of shelf-top images.
- **Kenney's skeleton was dropped.** It rendered tan and read as gingerbread. The Spark Coil (a Tesla coil built from primitives) replaced it in the Frankenstein pack.
- **Rug fix** (from the brief's known issues): the real file names are `ruground`, `rugrectangle`, `rugrounded`, and `rugsquare`.
- **Size fixes** (from the brief's known issues): the Power Generator is set to full floor-machine width (1.0). The glassware is sized against the desk.

## 5. Art pipeline (Rules 9 and 10)
- **Locked setup:**
  - One orthographic camera at (8, 7.2, 8), looking at (0, 1.4, 0).
  - One light rig: a hemisphere light plus a soft-shadow sun.
  - Frame 1600×1200. `scene.js` owns all of it.
- **Baking:** each item is rendered alone in its spot to a full-frame transparent PNG, then cropped with its offset kept. Stacking is pure layering with no anchor math, so the iPad needs no WebGL.
- **Shadows:** invisible shadow-only planes catch each item's shadow on the floor, the walls, and the baseboard (or on the bench top and shelf top for items that sit there).
- **The room shell is not an image.** It is 15 polygons plus floor-pattern tiles, and code shades them from the measured light. So paint recolors are free: no bake per color.
- **Rule 10 result** (`overlay-check/overlay_sheet.png`): four whole labs rendered two ways, as real 3D and as stacked images, then diffed.

| Lab | Within 8 shades | Wrong pixels beyond 1-px outlines (of 1.92 M) |
|---|---|---|
| Starter | 99.46% | 0 |
| Frankenstein | 99.33% | 12 |
| Designer paint | 99.09% | 185 |
| Upgraded | 99.12% | 1,160 |

- **Known limitation:** one item's shadow falling onto another item is not captured. The biggest case is the Grow Cabinet shading the side of the bench, which accounts for most of the Upgraded lab's 1,160 pixels. It reads as natural in the room. Fixing it would mean baking pairs of items.

- **Models:** 16 Kenney CC0 models from the GitHub mirror `Hidencod/tge-assets`. `sh fetch_models.sh` downloads them into `tools/lab-bake/models/`.

  - Space Kit: machine-generator
  - Cube Pets: animal-cat, animal-dog, animal-bunny

- **Everything else is built from primitives in `scene.js`:** beaker, flask, test tube rack, microscope, calorimeter, lab bench, grow cabinet, materials tester, spark coil, and the three graph posters.
- **Commands:** see `README.md`. `npm install` in `tools/lab-bake`, then `fetch_models.sh`, `bake.py`, `build_lab.py`, `smoke.py`, and `overlay_check.py`.
- **Headless Chromium needs WebGL:** `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`.
